# Demo (everything shown is working code; all data is synthetic and fictional)

## A. Side-by-side showcase in the offline viewer (main demo)
```sh
npm run showcase            # builds viewer/showcase.html (refuses to overwrite; delete it first to rebuild)
# open viewer/showcase.html in a browser (file://, no server, no network)
```
A committed copy of `viewer/showcase.html` is already in the repo and is tested to be byte-identical to a fresh build.

| | Scenario A "Eight documents agree" (`examples/showcase/deceptive.json`) | Scenario B "Three independent systems" (`examples/showcase/independent.json`) |
|---|---|---|
| Claim `door-0214` | 8 supporting items → **1 independent origin** → INSUFFICIENT, flagged FALSE CORROBORATION | 4 items → **3 origins** (CCTV clip is a declared copy of the recorder) → SUPPORTED under declared assumptions |
| Why | screenshots, forum post, article, PDF all derive from the badge export; the "anonymous tip" image declares the same hash as screenshot 1, and the "shared drive" image declares **no hash at all**. The tool hashes both files itself and finds them byte-identical (**verified**, node label "HASHED LOCALLY"). Engine 0.3.0, which only checked declared hashes, called this claim SUPPORTED with 2 origins | badge system, CCTV recorder and HVAC log have no declared link (graph shows them as "unknown", i.e. assumed, not established) |
| Abstention | — | `alarm-off`: two "independent" contractor reports have the same name and identical text → hard status SUPPORTED, **decision ABSTAINS** |
| Counterfactual plan | smallest change: **1** item from an origin outside the badge lineage; if it supports → SUPPORTED, if it contradicts → CONFLICTING, if none → stays INSUFFICIENT | `door-0214` robustness: loses SUPPORTED only if **2** of 3 origins collapse |
| Export | "Export report JSON" downloads the exact embedded, reproducible report | same |

## 180-second demo script (every step uses working, committed features)
Setup before recording: open `viewer/showcase.html` in a desktop browser window about 1400 px wide (two panels side by side). Have a terminal in the repository root.

| Time | On screen | Say (factual) |
|---|---|---|
| 0:00–0:15 | Title bar of the viewer | "Eight documents agree" is often one document echoed eight times. ProofGap X counts independent origins, not documents. |
| 0:15–0:50 | Left panel, claim `door-0214`: "8 supporting item(s) collapse to 1 independent origin(s)"; open "Why these count as 1 origin(s)" | Screenshots, a forum post, a news article and a PDF all derive from one badge export, as the case itself declares. The verdict is insufficient support, flagged as false corroboration. |
| 0:50–1:15 | Scroll to the graph in the left panel; hover the green arc into A8 | Two images were filed as an anonymous tip and a shared-drive find. The tool hashed the files itself: they are byte-identical to screenshot 1. A8 never declared a hash. The previous engine (0.3.0) called this claim supported. |
| 1:15–1:45 | Right panel: `door-0214` SUPPORTED (3 origins); then `alarm-off` with the "Abstains" badge | Three separate systems support the same claim, so it is supported under declared assumptions. Their independence is shown as unknown, not proven. Here the engine **abstains**: two "independent" contractor reports share a name and identical text. |
| 1:45–2:15 | Expand "Counterfactual evidence plan" on the left `door-0214` | The smallest change is one item from an origin outside the badge lineage. If it supports: supported. If it contradicts: conflicting. If none exists: unchanged. These are hypotheticals; nothing is claimed to exist. |
| 2:15–2:40 | Terminal: `npm test`, then `node src/cli.js examples/showcase/deceptive.json --evidence-dir examples/showcase/evidence --format text \| head -20` | The page is generated by the same engine as the CLI; 159 tests run locally. The viewer has no network access: its Content-Security-Policy blocks all requests, and case text is rendered as text only. |
| 2:40–2:55 | README "Known limitations" | Limits: if an author hides a shared source and leaves no trace, or a copy is re-encoded, the tool cannot know. It is not forensic software and never decides truth or guilt. |
| 2:55–3:00 | Repository URL | Open source; synthetic data only. |

Before recording: replace the last line with the public repository URL and licence once the owner has approved both. Do not say "open source" until the licence is committed and the repository is public.

## What the demo does NOT show
That any claim is true or false, that any file is authentic, or anyone's intent or guilt.
